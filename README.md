# ResiBee
ResiBee is a DIY embedded vision project that reads resistor color codes in real time using an STM32 Nucleo board (STM32H723ZG) and an ArduCAM OV2640 camera — with the entire CNN inference running on-device, no PC needed for the actual prediction.

for more details: https://loarri.wordpress.com/resibee/
